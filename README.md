# sdn-proxy-chaining

This project designs, implements, and benchmarks an application-layer HTTP Proxy Chaining architecture with Hybrid Cryptography inside a Software-Defined Networking (SDN) environment managed by Mininet and the Ryu OpenFlow controller. Aimed at mitigating metadata leakage and traffic profiling, the architecture decouples the sender's identity from the destination server by routing HTTP traffic through an arbitrary sequence of intermediate proxies using application-level source routing and JSON tunneling. End-to-end confidentiality is guaranteed through hybrid encryption combining RSA for symmetric session key exchange and Fernet (AES-128) for request and response payloads, ensuring intermediate forwarding nodes cannot inspect the plaintext data.
The framework evaluates the quantitative trade-off between anonymity and end-to-end latency across multi-subnet topologies varying from 3 to 10 network layers under diverse concurrency workloads. Experimental benchmarks highlight linear latency scaling with topological depth, analyze SDN flow-table dynamics (contrasting the cold-start overhead of sequential queries against data-plane flow caching under concurrency), and validate through traffic inspection that the exit proxy completely sanitizes client routing metadata before delivering requests to the target server.
